# Experience photos

You can add your own internship photos here. No coding is needed for the photos themselves.

Use these exact filenames:

- `sena-1.jpg` and `sena-2.jpg` → PT Solusi Energy Nusantara
- `petrokimia-1.jpg` and `petrokimia-2.jpg` → PT Petrokimia Gresik
- `pelindo-1.jpg` and `pelindo-2.jpg` → PT Pelindo Solusi Digital
- `digimarly-1.jpg` and `digimarly-2.jpg` → Digimarly

You can also use `.png` or `.webp`, but if you change the extension, update the corresponding filename in `index.html`.

Recommended: use original/high-resolution photos and keep each file reasonably compressed for a fast website.

The website automatically hides an empty photo slot when a file has not been added yet.
