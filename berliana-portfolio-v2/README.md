# Berliana Panca Dewi — International Internship Portfolio

Single-page portfolio designed for international internship / research applications.

## Included
- One-page section-based navigation (Home, About, Experience, Projects, Skills, Contact)
- Subtle scroll reveal animation
- Desktop cursor glow
- Project-card 3D pointer interaction
- Animated hero gradient blobs around the portrait
- Alternating dark-purple background tones per section
- Hero and About photos supplied by the user
- Company Profile links in Experience
- CV download button placeholder

## Add the CV
Place the final English CV PDF at:
`assets/Berliana-Panca-Dewi-Nurhidayah-CV.pdf`

## Add internship photos
The Experience section contains `mini-photo-placeholder` blocks. Replace each block with an `<img>` using approved, non-confidential internship photos.
